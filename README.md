# TSHUDの既定OFFについて

路線・車両の配布元からのご案内を踏まえ、一部のシナリオではTSHUDを最初からオフにしています。理由と配布元のご案内は、対象のシナリオを読み込んだときに確認できます。

## 路線・車両の作者の方へ

TSHUDを最初からオフにしてほしい場合や、対象の変更・取り下げをご希望の場合は、ちってまでご連絡ください。設定の更新はこちらで行います。GitHubアカウントやファイルの編集は不要です。

配布ページなどでご案内されているXアカウントからのDM、またはBOOTHのメッセージで受け付けています。

ご連絡は、以下の2行だけで大丈夫です。路線や車両の一部が対象の場合は、その範囲もお書き添えください。

```text
作品名：
希望：初めからオフ／対象の変更／取り下げ
```

- [X @chitte_101](https://x.com/chitte_101)のDM
- [BOOTHのメッセージ](https://chitte-101.booth.pm/)

## 配布データに設定を添える場合

マップと同じフォルダーに[TSHUD.policy.json](examples/TSHUD.policy.json)を配置すると、そのフォルダーのマップが対象になります。シナリオと同じフォルダーに置く場合は、[シナリオ名を指定する例](examples/scenario/TSHUD.policy.json)をご覧ください。シナリオとマップが同じフォルダーにある場合も、シナリオ名を指定します。
