# TSHUDの既定OFFリスト

配布元のご案内を踏まえ、対象のシナリオではTSHUDを初めからオフにしています。

## 現在の対象

| データ | 配布元からのご案内 |
|---|---|
| JR埼京線（cocoa様） | 埼京線では、外部ツールを使わずに遊んでほしいとのことです。[Xの投稿](https://x.com/NhtFvs/status/2122685818666123415) |
| 中央西線（くーせみ様） | 採点や画面表示を変える拡張機能を使ったプレイの公開についてご案内があります。[Xの投稿](https://x.com/kuusemi/status/2122570450664644792) |
| 城東急行電鉄（Mirai様） | 利用規約に、TSHUDを使った動画の投稿・配信についての記載があります。[配布元の利用規約](https://mirai-yokohama.sakura.ne.jp/bve.html) |

## リストの追加・訂正・取り下げ

抜けや誤りにお気づきの際は、お知らせいただけると助かります。作者の方に限らず、どなたでもフォークから修正を提案することが可能です。

1. このリポジトリをフォークし、[rules.json](rules.json)を編集します。対象データの条件を書き、`revision`を現在の`main`より1つ上げます。[定義の形式](schema.json)
2. [プルリクエスト](https://github.com/chitte-101/tshud-policy/pulls)を開き、作品名、変更理由、配布元の案内へのリンクを添えてください。
3. ちってが内容を確認し、取り込んだ変更が配信されます。

また、お問い合わせやその他のご相談は、[BOOTHのメッセージ](https://chitte-101.booth.pm/)またはXのDMまでお願いいたします。

## 配布データに設定を添える場合

マップと同じフォルダーに[TSHUD.policy.json](examples/TSHUD.policy.json)を配置すると、そのフォルダーのマップが対象になります。シナリオと同じフォルダーに置く場合は、[シナリオ名を指定する例](examples/scenario/TSHUD.policy.json)をご確認ください。シナリオとマップが同じフォルダーにある場合も、シナリオ名を指定します。
